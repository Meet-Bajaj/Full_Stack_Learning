# Background Jobs MCQs

1. **Question:** Why would you use a sandboxed processor in BullMQ?
   - A) To improve database read speeds.
   - B) To run CPU-intensive tasks without blocking the main Node.js event loop.
   - C) To isolate variables from other modules.
   - D) To prevent database connection pooling errors.
   - **Correct Answer:** B
   - **Explanation:** Sandboxed processors run in separate processes, keeping the main Node thread free to handle HTTP requests and lightweight tasks.
   - **Difficulty:** Intermediate
