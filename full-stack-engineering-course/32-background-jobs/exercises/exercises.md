# Background Jobs Exercises

## Exercise 1: Cron Jobs
Set up a BullMQ worker that processes a "daily-cleanup" job. Schedule the job to run automatically every minute (for testing purposes) using a cron expression.

## Exercise 2: NestJS Processor
Initialize a new NestJS module. Import `@nestjs/bullmq`, configure it to connect to localhost Redis, and build a basic processor that logs incoming job data.
