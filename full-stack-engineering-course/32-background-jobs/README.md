# Module 32: Background Jobs

## Overview
This module focuses on offloading heavy processing to background workers to ensure responsive applications.

## Learning Objectives
- Understand why and when to use background jobs
- Setup BullMQ workers
- Schedule recurring and delayed jobs
- Handle errors, retries, and dead letter queues
- Integrate background processing in NestJS

## Structure
- `lessons/`: Background job concepts and implementations
- `exercises/`: Building background processing systems
- `mcqs/`: Knowledge checks
- `interview.md`: Interview questions
- `assessment.md`: Final assessment
