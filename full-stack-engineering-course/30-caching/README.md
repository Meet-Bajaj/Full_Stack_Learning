# Module 30: Caching

## Overview
This module focuses on caching strategies to improve application performance and reduce load on primary databases.

## Learning Objectives
- Understand cache hits, misses, TTL, and eviction policies
- Master caching strategies like cache-aside and write-through
- Implement HTTP caching and application-level caching
- Solve cache invalidation challenges

## Structure
- `lessons/`: Caching strategies and patterns
- `exercises/`: Practical caching implementations
- `mcqs/`: Knowledge testing
- `interview.md`: Common interview questions
- `assessment.md`: Final module assessment
