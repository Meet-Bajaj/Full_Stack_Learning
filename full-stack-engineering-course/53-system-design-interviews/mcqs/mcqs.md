# Module 53: System Design - MCQs

## Beginner
**Q1: In system design, what does the CAP theorem state you cannot have simultaneously?**
A) Caching, Availability, Partition Tolerance
B) Consistency, Availability, Partition Tolerance
C) Consistency, Authenticity, Partition Tolerance
**Correct Answer:** B

## Intermediate
**Q2: Why is a Message Queue useful in a distributed system?**
A) It makes the system synchronous.
B) It decouples microservices and buffers traffic spikes.
C) It replaces the need for a database.
**Correct Answer:** B

## Advanced
**Q3: How do you prevent double-charging a user if their network drops during a payment request?**
A) Optimistic Locking
B) Idempotency Keys
C) Sticky Sessions
**Correct Answer:** B
