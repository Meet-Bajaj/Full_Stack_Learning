# Module 02: MCQs (Multiple Choice Questions)

This document contains MCQs spanning beginner to intermediate levels, covering all concepts in Module 02.

## Beginner Level (1-25)

**1. What is the primary purpose of a programming language?**
- A) To design user interfaces.
- B) To write instructions that computers can execute.
- C) To repair hardware issues.
- D) To browse the internet.
- **Correct**: B
- **Explanation**: Programming languages bridge the gap between human intent and machine execution.

**2. Which of the following is a "high-level" language?**
- A) Machine Code
- B) Assembly
- C) Python
- D) Binary
- **Correct**: C
- **Explanation**: Python abstracts away hardware details, making it a high-level language.

**3. What is a variable?**
- A) A mathematical constant that cannot change.
- B) A piece of hardware.
- C) A named storage location in memory for data.
- D) A network protocol.
- **Correct**: C

**4. Which of these is a Boolean value?**
- A) "True"
- B) 0
- C) TRUE
- D) null
- **Correct**: C
- **Explanation**: A boolean is strictly a logical True or False without quotes.

**5. What is the result of `5 + 3 * 2` based on operator precedence?**
- A) 16
- B) 11
- C) 10
- D) 30
- **Correct**: B
- **Explanation**: Multiplication happens before addition. 3*2=6; 5+6=11.

**6. Which operator is used to check if two values are equal?**
- A) `=`
- B) `==`
- C) `<=`
- D) `!=`
- **Correct**: B
- **Explanation**: A single `=` is for assignment. Double `==` is for comparison.

**7. In an `if/else` statement, when does the `else` block execute?**
- A) Always.
- B) When the `if` condition evaluates to TRUE.
- C) When the `if` condition evaluates to FALSE.
- D) When the program crashes.
- **Correct**: C

**8. What does DRY stand for?**
- A) Do Repeat Yourself
- B) Don't Repeat Yourself
- C) Data Resource Yield
- D) Dynamic Runtime Yield
- **Correct**: B

**9. Which loop is best used when you know exactly how many times you want to iterate?**
- A) while loop
- B) do-while loop
- C) for loop
- D) infinite loop
- **Correct**: C

**10. What is an infinite loop?**
- A) A loop that processes an infinite array.
- B) A loop where the termination condition is never met.
- C) A loop that takes a very long time to write.
- D) A nested loop.
- **Correct**: B

## Intermediate Level (26-50)

**26. In a dynamic typing system, what happens if you assign a string to a variable that previously held a number?**
- A) The program crashes with a Type Error.
- B) The variable is updated to hold the string without issue.
- C) The string is converted into a number.
- D) The compiler prevents you from running the code.
- **Correct**: B
- **Explanation**: Dynamic languages determine types at runtime and allow reassignment to different types.

**27. What is a "side effect" in the context of functions?**
- A) When a function returns an unexpected value.
- B) When a function modifies a variable outside of its local scope.
- C) When a function takes too long to execute.
- D) When a function crashes the program.
- **Correct**: B

**28. Given the array `arr = [10, 20, 30, 40]`, what is `arr[2]`?**
- A) 10
- B) 20
- C) 30
- D) 40
- **Correct**: C
- **Explanation**: Arrays are zero-indexed. 0->10, 1->20, 2->30.

**29. Why might you choose an Object (Dictionary) over an Array?**
- A) You need to access elements sequentially.
- B) You need to look up values using named keys rather than numeric indices.
- C) You want to sort the data alphabetically.
- D) You want to use a `for` loop efficiently.
- **Correct**: B

**30. What is the purpose of the `finally` block in error handling?**
- A) It runs only if an error occurs.
- B) It runs only if NO error occurs.
- C) It executes regardless of whether an error occurred or not.
- D) It restarts the program.
- **Correct**: C
- **Explanation**: `finally` is used for cleanup actions that must happen in both success and failure scenarios (like closing a file).
