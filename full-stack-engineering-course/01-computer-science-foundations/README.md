# Module 01: Computer Science Foundations

## Overview
Welcome to Computer Science Foundations! Before we write a single line of code, we need to understand the environment our code will run in. This module bridges the gap between the physical hardware and the abstract software we will build. We'll demystify how computers actually process information, how the internet routes data globally, and how operating systems manage resources.

## Learning Objectives
By the end of this module, you will be able to:
- Explain the interaction between CPU, RAM, and Storage using real-world analogies.
- Understand how data (text, images, numbers) is represented in binary format.
- Describe the role of an Operating System in process and memory management.
- Trace a network request from a web browser to a server and back.
- Understand the basics of the internet, including DNS, IP, and TCP/UDP.
- Describe common data structures and their appropriate use cases.
- Analyze the performance of simple algorithms using Big O notation.
- Differentiate between relational and non-relational databases.

## Why CS Foundations Matter
As a Full-Stack Engineer, you'll encounter problems that seem unsolvable if you only know JavaScript or Python. When a server runs out of memory, or a database query takes 10 seconds, or a network request times out—understanding the underlying systems is what separates junior developers from senior engineers. These foundations form the mental models you will use every day to design robust, scalable, and efficient software.
