# Cloud Computing MCQs (Module 39)

## Beginner
**1. Which AWS service is best suited for storing user-uploaded images?**
A) Amazon RDS
B) Amazon EC2
C) Amazon S3
D) Amazon EFS
**Answer:** C

## Intermediate
**2. What is the primary purpose of an AWS VPC?**
A) To run Docker containers.
B) To provide an isolated virtual network for your resources.
C) To manage user permissions.
D) To route DNS requests.
**Answer:** B

## Advanced
**3. When writing a Terraform script, what happens when you run `terraform plan`?**
A) It provisions the infrastructure in AWS.
B) It destroys the existing infrastructure.
C) It compares the current state to the desired state and outputs the execution plan without making changes.
D) It downloads the necessary AWS plugins.
**Answer:** C
