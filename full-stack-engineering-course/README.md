## 📋 What Is This?

This is a **complete, self-contained Full-Stack Engineering course** designed to take you from absolute beginner to professional-level full-stack engineer. It is structured as a local learning repository that you can study from at your own pace.

This is NOT just a list of topics. This is a **complete curriculum** with:

- 📖 **56 comprehensive modules** covering every aspect of full-stack development
- 💻 **Hundreds of code examples** — all realistic and production-oriented
- 🧪 **5,000+ MCQ questions** across all difficulty levels
- 🏗️ **25+ progressive projects** from todo apps to production SaaS platforms
- 📝 **Exercises and challenges** for every concept
- 🎯 **Interview preparation** for Junior through Senior roles
- 📊 **Progress tracking** with checkboxes and completion metrics
- 🌐 **Local learning website** with search, quizzes, and dark/light mode
- 📋 **Cheat sheets** for every major technology
- 🔧 **Troubleshooting guides** for real-world debugging
- 🏆 **3 capstone projects** that use the entire technology stack

## 🏁 How to Use This Course

### 1. Start with Orientation
Read [Module 00: Orientation](./00-orientation/) to understand how the course works.

### 2. Follow the Learning Path
Open [LEARNING_PATH.md](./LEARNING_PATH.md) and follow the recommended order.

### 3. For Each Module
```
1. Read the module README.md
2. Complete lessons in order (lessons/)
3. Do the exercises (exercises/)
4. Build the projects (projects/)
5. Take the MCQ quiz (mcqs/)
6. Review the cheat sheet (cheatsheet.md)
7. Study interview questions (interview.md)
8. Take the assessment (assessment.md)
9. Update your progress (progress.md)
```

### 4. Use the Course Website
Launch the local learning website for an interactive experience:
```bash
cd course-website
npm install
npm run dev
```

### 5. Track Your Progress
Open [PROGRESS.md](./PROGRESS.md) to track your overall progress.

## 📖 Course Philosophy

> **"Understanding WHY things work is more important than memorizing HOW to use them."**

This course is built on these principles:

1. **Fundamentals First** — Master the basics before touching frameworks
2. **Progressive Complexity** — Each concept builds on previous ones
3. **Learn by Doing** — 80% of learning happens through coding
4. **Real-World Focus** — Every example reflects actual engineering practices
5. **Depth Over Breadth** — Better to deeply understand 10 things than superficially know 100
6. **Security by Default** — Security is integrated, not bolted on
7. **Production Thinking** — Consider deployment, monitoring, and maintenance from the start
