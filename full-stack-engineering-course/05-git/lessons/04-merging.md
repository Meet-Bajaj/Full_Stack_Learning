# Lesson 4: Merging

## Merging Concepts
Merging brings changes from one branch into another.
- **Fast-forward merge**: No divergent history. Git just moves the pointer forward.
- **Three-way merge**: Divergent history. Git creates a new merge commit.

## Resolving Conflicts
When two branches modify the same part of a file differently, Git pauses the merge and asks you to resolve the conflict manually.
