# Lesson 1: Version Control Concepts

## What is Version Control?
Version control is a system that records changes to a file or set of files over time so that you can recall specific versions later.

## Mental Model
Think of Git as a **time machine + parallel universes** for your code.
- **Time machine**: You can go back in time to any previous state of your project.
- **Parallel universes**: You can create branches to work on features simultaneously without affecting the main timeline.

## Centralized vs Distributed
- **Centralized (CVCS)**: Single server contains all versioned files. (e.g., Subversion).
- **Distributed (DVCS)**: Clients fully mirror the repository. (e.g., Git).
