# Module 05: Git

Welcome to the Git module! In this module, you will learn the fundamental and advanced concepts of Git, the most popular distributed version control system.

## Learning Objectives
- Understand version control and why Git is essential.
- Master Git fundamentals: init, add, commit, status.
- Effectively branch and merge.
- Understand the difference between rebasing and merging.
- Manage Git history, tags, and undo changes.
- Implement advanced Git features and workflows.

## Module Structure
- `lessons/`: Detailed concept lessons.
- `exercises/`: Scenario-based exercises.
- `mcqs/`: Multiple-choice questions.
- `projects/`: Practice projects.
