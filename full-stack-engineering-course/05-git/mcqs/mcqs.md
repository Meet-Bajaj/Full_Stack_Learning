# Git MCQs

1. Which command initializes a Git repository?
   A) git start
   B) git init
   C) git create
   D) git new
   **Answer**: B. Explanation: `git init` creates the `.git` directory.

2. What does `git rebase` do?
   A) Merges two branches
   B) Reapplies commits on top of another base tip
   C) Undoes a commit
   D) Deletes a branch
   **Answer**: B.
