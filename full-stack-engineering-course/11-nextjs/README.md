# Module 11: Next.js

Next.js is a React framework for building full-stack web applications. 

## Why Next.js?
Next.js simplifies building complex applications by providing built-in routing, rendering strategies, and optimizations out of the box.

## Rendering Strategies
- **CSR (Client-Side Rendering):** Renders in the browser. Good for highly interactive, private pages.
- **SSR (Server-Side Rendering):** Renders on each request. Good for dynamic content needing SEO.
- **SSG (Static Site Generation):** Renders at build time. Best for performance and SEO.
- **ISR (Incremental Static Regeneration):** Updates static pages in the background without rebuilding the entire site.
