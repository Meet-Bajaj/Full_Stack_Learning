# Next.js Exercises

## Exercise 1: Setup
Initialize a new Next.js project using `create-next-app` with TypeScript and Tailwind CSS.

## Exercise 2: Routing
Create a folder structure for a blog with the following routes:
- `/` (Home)
- `/blog` (Blog List)
- `/blog/[slug]` (Individual Blog Post)

## Exercise 3: Data Fetching
Fetch a list of users from `https://jsonplaceholder.typicode.com/users` in a Server Component and display them in a list.

## Exercise 4: Server Actions
Create a form that submits user data (name, email) to a Server Action. Log the data on the server and return a success message.
