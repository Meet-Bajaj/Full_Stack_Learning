# Next.js Projects

## Project 1: Personal Blog
**Difficulty:** Beginner
**Requirements:**
- Static Routing (`/`, `/about`, `/blog`)
- Dynamic Routing (`/blog/[slug]`)
- Render Markdown using `next-mdx-remote` or `gray-matter`.

## Project 2: Issue Tracker Dashboard
**Difficulty:** Intermediate
**Requirements:**
- Authentication with NextAuth.js
- CRUD operations for issues
- Server Actions for form submissions
- Middleware for route protection

## Project 3: E-Commerce Storefront
**Difficulty:** Advanced
**Requirements:**
- Product listing with filtering and pagination
- Shopping cart functionality (Client Components)
- Incremental Static Regeneration (ISR) for product pages
- Integration with a payment gateway (e.g., Stripe)
