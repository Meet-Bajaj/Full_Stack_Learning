# Deployment MCQs (Module 40)

## Beginner
**1. What does CI/CD stand for?**
A) Continuous Integration / Continuous Deployment
B) Code Inspection / Code Delivery
C) Central Integration / Central Deployment
D) Container Integration / Container Delivery
**Answer:** A

## Intermediate
**2. Why should you use multi-stage builds in Docker for production?**
A) To run multiple apps in one container.
B) To keep the final image size small by omitting build dependencies (like compilers or devDependencies).
C) Because Nginx requires it.
D) To speed up the database.
**Answer:** B

## Advanced
**3. In a Blue-Green deployment strategy, how is the switch between versions handled?**
A) The server is restarted.
B) The load balancer or reverse proxy configuration is updated to route traffic from the old environment to the new environment.
C) The database schema is migrated.
D) DNS records are updated.
**Answer:** B
