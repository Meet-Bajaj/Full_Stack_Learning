# Lesson 2: Logging in Node.js

## Learning Objectives
- Implement structured logging in Node.js using Pino or Winston.
- Understand the importance of request logging.
- Implement Correlation IDs to track requests across asynchronous boundaries.

## Choosing a Logger
`console.log` is insufficient for production. It is synchronous (blocking the event loop), lacks log levels, and outputs plain text.

Two popular structured loggers for Node.js are:
1. **Winston**: Highly configurable, widely used, supports multiple transports (destinations).
2. **Pino**: Extremely fast, focused on low overhead, outputs JSON by default.

## Implementing Pino

```typescript
import pino from 'pino';

// Initialize logger
const logger = pino({
  level: process.env.LOG_LEVEL || 'info',
  // Redact sensitive keys automatically
  redact: ['req.headers.authorization', 'user.password'] 
});

logger.info('Server started on port 3000');
logger.error({ err: new Error('DB Connection Failed') }, 'Database error occurred');
```

## Request Logging & Correlation IDs
When handling thousands of requests per minute, logs from different requests get interleaved. How do you find all the logs for *one specific* user request?

**Correlation IDs (or Request IDs)** solve this. You generate a unique ID (UUID) at the start of a request and attach it to every log message emitted during that request.

```typescript
import express from 'express';
import pino from 'pino';
import pinoHttp from 'pino-http';
import { v4 as uuidv4 } from 'uuid';

const app = express();
const logger = pino();

// Middleware to inject correlation ID and log requests
app.use(pinoHttp({
  logger,
  genReqId: function (req, res) {
    // Use existing trace header if present, otherwise generate one
    return req.headers['x-request-id'] || uuidv4();
  }
}));

app.get('/api/data', (req, res) => {
  // Access the logger attached to the request
  req.log.info('Processing data fetch');
  
  // Do some work...
  
  res.json({ success: true });
});
```
With `pino-http`, every log generated by `req.log` automatically includes the `req.id`, allowing you to filter your log aggregator for that specific ID and see the entire lifecycle of the request.

## Summary
Using a dedicated logging library like Pino ensures your logs are fast, structured, and safe. Implementing Correlation IDs is non-negotiable for debugging concurrent requests in a Node.js server.
