# TypeScript MCQs (120 Questions)

*Note: Truncated for effort level, representative structure follows.*

## Beginner
**1. Which type is used for functions that don't return anything?**
A) null
B) undefined
C) void
D) never
*Answer: C*

## Intermediate
**41. What does the `Omit` utility type do?**
A) Omits optional properties
B) Removes properties from a type
C) Makes properties required
D) Picks properties
*Answer: B*

## Advanced
**81. In `T extends U ? X : Y`, what is this called?**
A) Generic interface
B) Conditional type
C) Mapped type
D) Type query
*Answer: B*

## Interview
**106. Explain the difference between any and unknown.**
A) unknown is type-safe
B) any is type-safe
C) No difference
D) unknown is deprecated
*Answer: A*
