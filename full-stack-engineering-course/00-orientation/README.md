# Module 00: Orientation

Welcome to the Full-Stack Engineering Course! This module serves as your introduction and guide on how to successfully navigate and extract the most value from this comprehensive curriculum.

## What is this course?

This course is designed to take you from knowing basic programming (or being a self-taught intermediate) to a highly competent, job-ready Full-Stack Software Engineer. It focuses heavily on modern web development technologies, system design, scalable architectures, and best practices.

Rather than just teaching you the "How" (syntax and APIs), this course emphasizes the "Why". We focus on mental models, trade-offs, and underlying mechanisms that power the tools we use daily. 

## Learning Methodology

To master complex engineering topics, passive learning (watching videos or reading without coding) is insufficient. We've structured this course based on cognitive science principles:

- **20% Theory & Conceptual Foundations:** Understanding the 'Why', mental models, and real-world analogies.
- **30% Guided Coding & Code Reading:** Walkthroughs, exploring production-grade code, and syntax deep-dives.
- **20% Hands-On Exercises:** Debugging, fill-in-the-blanks, and isolated feature implementation.
- **15% Project Building:** Applying concepts holistically in real-world applications.
- **10% Testing & MCQs:** Spaced repetition, scenario-based questioning, and active recall.
- **5% Revision & Assessment:** Ensuring long-term retention and synthesis of cross-cutting concerns.

## Tools You Will Need

Before you dive into the code, ensure your environment is fully set up. We'll cover this in detail in Lesson 03, but here is a quick overview of what you'll be installing:
- **Editor:** VS Code (with essential extensions)
- **Runtime Environment:** Node.js (via nvm)
- **Version Control:** Git
- **Containerization:** Docker Desktop
- **Databases:** PostgreSQL (Relational), MongoDB (NoSQL), Redis (Caching)
- **Browser:** Google Chrome or Firefox Developer Edition

## Study Tips and Time Management

- **Consistency over Intensity:** 1-2 hours a day, 5 days a week is far better than a single 10-hour binge on Sunday.
- **Embrace the Struggle:** When you get stuck (and you will), give yourself 30 minutes to figure it out before looking at the solution. This is called *productive failure* and is crucial for memory formation.
- **Avoid Tutorial Hell:** Don't just copy-paste code. Type it out, break it, and see what error messages appear. Try modifying the code to see how the system reacts.
- **Use the Assessments:** Don't skip the MCQs and Assessments. They are designed to expose the gaps in your mental models.
