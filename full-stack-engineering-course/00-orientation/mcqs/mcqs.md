# Module 00 MCQs

**1. What is the primary focus of this course's teaching philosophy?**
A) Memorizing syntax for specific languages
B) Understanding the "Why" and mental models behind technologies
C) Watching video tutorials passively
D) Copy-pasting code to build projects quickly
**Correct:** B
**Explanation:** The course emphasizes understanding underlying mechanisms and trade-offs rather than just memorizing APIs, ensuring your skills remain relevant even as specific tools change.

**2. Which of the following is an example of "Deliberate Practice"?**
A) Watching a 4-hour tutorial video straight through
B) Copying code from a lesson into your editor
C) Building a project from a tutorial, then immediately rebuilding it from scratch with slight variations
D) Reading documentation without writing any code
**Correct:** C
**Explanation:** Deliberate practice requires active engagement, recalling information from memory, and applying concepts independently without simply following a guide.

**3. What is the recommended way to install Node.js?**
A) Downloading the installer directly from nodejs.org
B) Using NVM (Node Version Manager)
C) Using Homebrew on a Mac
D) Installing it globally via npm
**Correct:** B
**Explanation:** NVM allows you to easily switch between different versions of Node.js, which is essential when working on multiple projects that may have different version requirements.

**4. When encountering a massive error log, what is the best first step?**
A) Immediately search the exact error text on StackOverflow
B) Delete the last lines of code you wrote and try again
C) Read the error from top to bottom, looking for the error type and a line number referencing your own code
D) Ask a senior developer for help immediately
**Correct:** C
**Explanation:** Error logs often contain the exact file and line number causing the issue. Finding the reference to your own code (ignoring library code traces) is crucial for effective debugging.
