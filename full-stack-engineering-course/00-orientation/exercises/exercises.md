# Module 00 Exercises

*(Note: Since this is an orientation module, there are no heavy coding exercises. These are thought exercises to establish your environment and workflow.)*

## Exercise 1: Environment Verification
Open your terminal and run the following commands. Ensure none of them return "command not found". 

```bash
node -v
npm -v
git --version
docker --version
```

## Exercise 2: Terminal Navigation
Using ONLY your terminal (no graphical file explorer), perform the following sequence:
1. Create a folder named `test-environment` on your Desktop.
2. Navigate into that folder.
3. Create a file named `hello.txt`.
4. Navigate back to your Desktop.
5. Delete the `test-environment` folder.

## Exercise 3: The Feynman Technique Practice
Write down a one-paragraph explanation of what a "Growth Mindset" is, as if you were explaining it to a middle school student who just failed a math test.
