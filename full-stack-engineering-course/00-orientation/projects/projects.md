# Module 00 Projects

*(Note: There are no full projects for the Orientation module. The "project" is to ensure your computer is fully configured for the rest of the course.)*

## Milestone: Hello World

**Objective:** Prove your environment is working.

1. Open VS Code.
2. Open the built-in terminal.
3. Create a folder called `first-project` and navigate into it.
4. Run `npm init -y`
5. Create a file called `index.js`.
6. Add the following code: `console.log("Environment configured successfully!");`
7. Run the file using `node index.js`.
8. Delete the folder.
