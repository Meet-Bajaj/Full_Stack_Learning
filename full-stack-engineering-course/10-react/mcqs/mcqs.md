# React MCQs Bank

*Contains 150 scenario-based questions.*

## Beginner (50 Questions)
1. **Question:** What is JSX?
   - A) A new language
   - B) A syntax extension for JavaScript
   - C) A CSS framework
   - D) A database query language
   - **Answer:** B
   - **Explanation:** JSX allows you to write HTML-like syntax within JavaScript.

## Intermediate (50 Questions)
51. **Question:** What is the primary purpose of `useEffect`?
   - A) To define component styles
   - B) To synchronize a component with an external system
   - C) To handle form validation
   - D) To create context providers
   - **Answer:** B
   - **Explanation:** `useEffect` is for handling side effects like data fetching, subscriptions, or manually changing the DOM.

## Advanced (30 Questions)
101. **Question:** How does React.memo optimize performance?
   - A) By memoizing the DOM nodes
   - B) By preventing re-renders if props have not changed
   - C) By caching API responses
   - D) By compiling components to static HTML
   - **Answer:** B
   - **Explanation:** `React.memo` is a higher-order component that skips rendering when props remain the same.

## Interview (20 Questions)
131. **Question:** Can you explain the difference between `useMemo` and `useCallback`?
   - A) `useMemo` memoizes a value, `useCallback` memoizes a function.
   - B) There is no difference.
   - C) `useMemo` is for state, `useCallback` is for effects.
   - D) `useCallback` is only used in class components.
   - **Answer:** A
   - **Explanation:** `useMemo` returns a memoized value, while `useCallback` returns a memoized callback function.
