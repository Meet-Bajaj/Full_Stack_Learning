# Lesson 1: VPS Fundamentals

## What is a VPS?
A Virtual Private Server (VPS) is a virtual machine sold as a service by an Internet hosting provider. It runs its own copy of an operating system, providing customers with superuser-level access to that operating system instance.

## VPS Providers
- **DigitalOcean:** Known for its developer-friendly interface and "Droplets".
- **Linode (Akamai):** Excellent performance and documentation.
- **Hetzner:** Extremely cost-effective, particularly in Europe.
- **AWS EC2:** More complex but integrates with the vast AWS ecosystem.

## Choosing a VPS
When selecting a VPS, consider:
- RAM (Minimum 1GB, 2-4GB recommended for Node/DB stacks)
- CPU Cores
- Storage (SSD/NVMe)
- Bandwidth limits
- Location (closest to your users)

## Real-World Analogy
Renting a VPS is like renting an apartment. You share the building (physical server) with others, but you have your own secure space (VM), your own key (root access), and you can decorate it however you like (install any software).
