# Module 38: VPS (Virtual Private Server)

## Overview
A Virtual Private Server (VPS) provides you with dedicated resources on a shared physical server. It's the standard way to host full-stack applications in production without the complexity and cost of managed cloud services.

## Learning Objectives
- Provision and configure a Linux VPS.
- Secure a VPS using SSH keys and firewalls.
- Install and configure necessary software (Docker, Nginx, Node).
- Manage DNS records for domain names.
- Automate backups and monitor server health.

## Module Structure
- `lessons/`: Step-by-step guides on server setup and management.
- `exercises/`: Practical server configuration tasks.
- `mcqs/`: Knowledge checks on Linux and server administration.
- `projects/`: Complete server provisioning project.

## Prerequisites
- Nginx fundamentals (Module 37).
- Basic Linux administration skills.
