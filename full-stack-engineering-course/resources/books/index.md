# 📚 Essential Engineering Books
> Classic and modern literature for software architects

---

## 🌟 Curated Gold Standard Catalog

### 1. Core Architecture & Fundamentals
- **Designing Data-Intensive Applications (Martin Kleppmann)** — The undisputed masterwork on reliability, scalability, replication, partitioning, and distributed transactions.
- **Clean Architecture (Robert C. Martin)** — Foundational guidance on dependency inversion, boundary separation, and business rules isolation.
- **Refactoring: Improving the Design of Existing Code (Martin Fowler)** — Code smells, incremental refactoring techniques, and test-driven design.

### 2. Official Documentation Portals
- **Node.js:** [nodejs.org/docs](https://nodejs.org/docs) — Official runtime API and Event Loop guides.
- **TypeScript:** [typescriptlang.org/docs](https://www.typescriptlang.org/docs/) — Complete handbook, TSConfig reference, utility types.
- **PostgreSQL:** [postgresql.org/docs](https://www.postgresql.org/docs/) — Manuals, index internals, and SQL syntax.
- **Prisma:** [prisma.io/docs](https://www.prisma.io/docs) — ORM schema guides, client methods, and migration runbooks.
- **Docker:** [docs.docker.com](https://docs.docker.com/) — Reference guides for Dockerfile, Compose, and networking.
