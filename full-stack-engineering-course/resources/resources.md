# Comprehensive Resource Directory

This document provides recommended learning resources for every major technology covered in the Full-Stack Engineering Course.

## JavaScript & TypeScript
### Official Documentation
- [MDN Web Docs - JavaScript](https://developer.mozilla.org/en-US/docs/Web/JavaScript)
- [TypeScript Handbook](https://www.typescriptlang.org/docs/handbook/intro.html)
- [ECMAScript Specification](https://tc39.es/ecma262/)

### Books
- *Eloquent JavaScript* by Marijn Haverbeke
- *You Don't Know JS Yet* by Kyle Simpson
- *Effective TypeScript* by Dan Vanderkam

### Practice Platforms
- [LeetCode (JS/TS tracks)](https://leetcode.com)
- [Exercism (JavaScript)](https://exercism.org/tracks/javascript)
- [Type-Level TypeScript](https://type-level-typescript.com/)
