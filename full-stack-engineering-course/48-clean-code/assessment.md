# Clean Code Assessment

## Part 1: Multiple Choice
1. What is the Boy Scout Rule?
   a) Always write tests before code.
   b) Always leave the code cleaner than you found it.
   c) Always comment your code thoroughly.

2. Which of the following is a code smell?
   a) A function with 0 arguments.
   b) A function that takes a boolean flag as an argument.
   c) Throwing a custom Error class.

## Part 2: Code Review
**Task:** Review a provided block of code. Identify at least 4 clean code violations (naming, function length, side effects, poor comments) and rewrite the code snippet to be clean.

## Part 3: Theory
**Question:** Explain the difference between returning `null` vs throwing a `NotFoundError`. Why is the latter generally preferred in Clean Code?
