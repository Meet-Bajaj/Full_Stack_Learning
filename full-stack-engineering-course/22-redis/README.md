# Module 22: Redis

## Overview
Redis is an open-source, in-memory data structure store used as a database, cache, message broker, and streaming engine.

## Learning Objectives
- Understand memory-based storage vs persistent disk storage.
- Master Redis data types (Strings, Hashes, Lists, Sets, Sorted Sets).
- Implement caching strategies, session management, and rate limiting.
- Understand Pub/Sub, Streams, and distributed locks.
