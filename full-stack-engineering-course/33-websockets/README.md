# Module 33: WebSockets

## Overview
WebSockets provide a persistent, full-duplex communication channel over a single TCP connection, enabling real-time capabilities in web applications.

## Learning Objectives
- Understand the limitations of HTTP for real-time data
- Implement WebSocket servers and clients
- Use Socket.IO for robust real-time communication
- Scale WebSocket connections across multiple servers
- Secure WebSocket endpoints
