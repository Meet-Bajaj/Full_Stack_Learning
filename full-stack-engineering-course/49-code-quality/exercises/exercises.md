# Code Quality Exercises

## 1. ESLint & Prettier Setup
**Task:** Given a fresh Node.js project, install and configure ESLint and Prettier. Run the linter on a provided messy file and fix all auto-fixable errors using the CLI.

## 2. Husky Pre-commit Hook
**Task:** Configure Husky and `lint-staged` in a `package.json` file so that `eslint --fix` runs only on staged `.ts` files when a developer attempts to run `git commit`.

## 3. Code Review Simulation
**Task:** Review a provided GitHub Pull Request. Write exactly 3 pieces of constructive feedback. Focus on logic, security, and architecture, ignoring formatting.

## 4. Writing an ADR
**Task:** Write an Architecture Decision Record (ADR) detailing the team's decision to adopt strict TypeScript mode across the codebase. Include context, decision, and consequences.
