# Module 25: Docker Compose

## Overview
Learn Docker Compose for orchestrating multi-container applications.

## Learning Objectives
- Write docker-compose.yml files
- Configure services, networks, and volumes
- Set up development and production environments
- Manage full-stack applications with Compose

## Structure
- `lessons/`: Detailed explanations of Compose concepts
- `mcqs/`: Multiple choice questions
- `exercises/`: Hands-on practice
- `projects/`: Real-world projects
- `examples/`: Code examples
