# Lesson 12: Coding Challenges

## Learning Objectives
- Understand the common algorithmic patterns used in interviews.
- Master time and space complexity analysis (Big O notation).
- Learn strategies for whiteboard/coderpad interviews.

## 1. Algorithmic Patterns

Instead of memorizing hundreds of problems, learn the underlying patterns:
- **Two Pointers:** Great for sorted arrays or strings (e.g., Two Sum, Palindrome check).
- **Sliding Window:** Used for finding subarrays or substrings (e.g., Longest substring without repeating characters).
- **Fast and Slow Pointers:** Useful for cycle detection in linked lists.
- **Breadth-First Search (BFS):** Level-order traversal in trees or shortest path in unweighted graphs. Uses a Queue.
- **Depth-First Search (DFS):** Traversing to the leaves first. Used in mazes, generating permutations. Uses recursion or a Stack.

## 2. Time and Space Complexity (Big O)

Big O notation describes how the runtime or memory requirements scale as the input size (N) grows.
- **O(1):** Constant. Accessing an array index or hash map key.
- **O(log N):** Logarithmic. Binary search.
- **O(N):** Linear. Iterating through an array once.
- **O(N log N):** Log-linear. Efficient sorting algorithms (Merge Sort, Quick Sort).
- **O(N^2):** Quadratic. Nested loops.

## 3. The "Think Out Loud" Protocol

1. **Understand:** Repeat the problem. Ask clarifying questions. Check edge cases.
2. **Match:** Match the problem to known patterns.
3. **Plan:** Describe your approach before writing code. Analyze the Big O.
4. **Implement:** Write the code. Keep it clean and modular.
5. **Review:** Dry run your code with an example input to catch bugs.

## Summary & Checklist
- [ ] Master the top 5 algorithmic patterns.
- [ ] Be able to calculate Big O time and space complexity for your solutions.
- [ ] Practice the 5-step Think Out Loud protocol in mock interviews.
