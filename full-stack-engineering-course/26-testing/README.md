# Module 26: Testing

## Overview
This module covers comprehensive testing strategies for full-stack applications, ranging from unit tests to end-to-end testing, utilizing tools like Jest, Vitest, React Testing Library, and Playwright.

## Learning Objectives
- Understand the testing pyramid and testing mindset.
- Write robust unit, integration, and E2E tests.
- Master mocking, spying, and stubbing.
- Implement automated testing in CI/CD pipelines.

## Module Structure
- `lessons/`: Detailed theoretical and practical lessons.
- `exercises/`: Hands-on practice exercises.
- `projects/`: Practical implementation of tests on existing apps.
- `mcqs/`: Multiple-choice questions for knowledge check.

## Prerequisites
- Proficiency in JavaScript/TypeScript.
- Experience with React and Express/NestJS.
