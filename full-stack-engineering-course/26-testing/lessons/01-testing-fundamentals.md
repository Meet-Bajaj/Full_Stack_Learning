# Lesson 1: Testing Fundamentals

## Learning Objectives
- Understand what testing is and why it's critical.
- Grasp the Testing Pyramid.
- Differentiate between TDD and BDD.

## The Testing Pyramid
1. **Unit Tests**: Fast, isolated, test individual functions/components. (Bottom of pyramid, highest volume)
2. **Integration Tests**: Ensure multiple units work together (e.g., database + API).
3. **E2E Tests**: Simulate real user scenarios. Slowest, most expensive. (Top of pyramid)

## Mental Model
Think of testing like building a car.
- Unit tests: Checking each bolt and gear before assembly.
- Integration tests: Checking if the engine connects to the transmission.
- E2E tests: Taking the fully assembled car for a test drive.

## Summary Checklist
- [ ] I understand the testing pyramid.
- [ ] I know the difference between TDD (Test-Driven Development) and BDD (Behavior-Driven Development).
