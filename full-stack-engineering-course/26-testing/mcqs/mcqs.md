# Module 26: Testing MCQs

1. **Which testing level is at the bottom of the Testing Pyramid?**
   - A) E2E Tests
   - B) Unit Tests
   - C) Integration Tests
   - D) Manual Tests
   - **Answer**: B
   - **Explanation**: Unit tests form the base of the pyramid as they are fast and numerous.

2. **What does the AAA pattern stand for in testing?**
   - A) Arrange, Act, Assert
   - B) Allocate, Access, Affirm
   - C) Assign, Action, Audit
   - D) Assert, Act, Arrange
   - **Answer**: A
   - **Explanation**: Arrange sets up the test, Act executes the code, and Assert verifies the outcome.
