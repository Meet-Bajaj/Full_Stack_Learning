# System Design MCQs

1. **Question:** In the CAP theorem, what does Partition Tolerance mean?
   - A) The system can tolerate database partitions.
   - B) The system continues to operate despite network communication failures between nodes.
   - C) The system partitions data equally among all available nodes.
   - D) The system tolerates high latency during partition rebalancing.
   - **Correct Answer:** B
   - **Explanation:** Partition tolerance ensures the system functions even if network links between nodes drop.
   - **Difficulty:** Intermediate

2. **Question:** Which caching strategy writes data to the cache and the database simultaneously?
   - A) Cache-aside
   - B) Write-behind
   - C) Write-through
   - D) Read-through
   - **Correct Answer:** C
   - **Explanation:** Write-through caching ensures high consistency between cache and DB by writing to both synchronously.
   - **Difficulty:** Beginner
