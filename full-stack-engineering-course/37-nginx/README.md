# Module 37: Nginx

## Overview
Nginx is a highly scalable, high-performance web server, reverse proxy, and load balancer. In this module, you will learn the core concepts of Nginx, how to configure it, and how to use it for reverse proxying, load balancing, and serving static files.

## Learning Objectives
- Understand the event-driven architecture of Nginx.
- Configure Nginx as a web server for static files.
- Configure Nginx as a reverse proxy for Node.js/NestJS apps.
- Implement SSL/TLS with Let's Encrypt.
- Set up load balancing across multiple backend servers.
- Secure Nginx configurations.

## Module Structure
- `lessons/`: Detailed lessons on Nginx concepts and configurations.
- `exercises/`: Hands-on configuration exercises.
- `mcqs/`: Multiple-choice questions for knowledge check.
- `projects/`: Real-world Nginx deployment scenarios.

## Prerequisites
- Basic Linux command line knowledge.
- Understanding of HTTP and networking concepts.
