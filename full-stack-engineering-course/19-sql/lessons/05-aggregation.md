# Lesson 05: Aggregation

## 1. Introduction and Learning Objectives
Often, we don't want to see individual rows; we want summary data. We want to know the "total sales", "average age", or "number of users". This is done using aggregate functions.

**Learning Objectives:**
- Use aggregate functions like `COUNT`, `SUM`, `AVG`, `MIN`, `MAX`.
- Group data using the `GROUP BY` clause.
- Filter grouped data using the `HAVING` clause.

---

## 2. Aggregate Functions

Aggregate functions perform a calculation on a set of values and return a single value.

- **`COUNT()`**: Returns the number of rows.
- **`SUM()`**: Returns the total sum of a numeric column.
- **`AVG()`**: Returns the average value of a numeric column.
- **`MIN()` / `MAX()`**: Returns the smallest/largest value.

```sql
-- Total number of users
SELECT COUNT(*) FROM users;

-- Total revenue
SELECT SUM(total_amount) FROM orders;

-- Average price of products
SELECT AVG(price) FROM products;

-- Highest price
SELECT MAX(price) FROM products;
```

### `COUNT(*)` vs `COUNT(column)`
- `COUNT(*)` counts total rows, including rows with NULLs.
- `COUNT(column)` counts only rows where `column` is NOT NULL.

---

## 3. The GROUP BY Clause

What if we want the total revenue **per customer**? Or the count of users **per country**? We use `GROUP BY`.

`GROUP BY` groups rows that have the same values into summary rows.

```sql
-- Count of users in each country
SELECT country, COUNT(*) AS user_count
FROM users
GROUP BY country;

-- Total spent by each user
SELECT user_id, SUM(total_amount) AS total_spent
FROM orders
GROUP BY user_id;
```

**CRITICAL RULE:** In a `SELECT` statement with `GROUP BY`, every column in the `SELECT` list must either be an aggregate function or be present in the `GROUP BY` clause.

---

## 4. Filtering Aggregates: The HAVING Clause

What if we only want to see customers who have spent *more than $500*?

We cannot use `WHERE` because `WHERE` filters rows *before* aggregation happens. We must use `HAVING`, which filters *after* aggregation.

```sql
SELECT user_id, SUM(total_amount) AS total_spent
FROM orders
GROUP BY user_id
HAVING SUM(total_amount) > 500;
```

### WHERE vs HAVING
```sql
SELECT country, COUNT(*) as active_users
FROM users
WHERE status = 'active'     -- 1. Filter rows first
GROUP BY country            -- 2. Group the remaining rows
HAVING COUNT(*) > 100;      -- 3. Filter the aggregated groups
```

---

## 5. Aggregation with Joins

You will frequently combine `JOIN`s and `GROUP BY`.

```sql
-- Get the total revenue generated by each product category
SELECT c.name AS category_name, SUM(p.price * o.quantity) AS total_revenue
FROM categories c
JOIN products p ON c.id = p.category_id
JOIN order_items o ON p.id = o.product_id
GROUP BY c.name
ORDER BY total_revenue DESC;
```

---

## 6. Summary & Checklist

**Summary:**
Aggregation functions allow us to calculate metrics across our dataset. `GROUP BY` allows us to bucket these calculations by specific categories. `HAVING` filters the results of aggregates, whereas `WHERE` filters raw rows.
