# Module 19: SQL

## Overview
Welcome to the SQL (Structured Query Language) module. This comprehensive module covers everything from basic querying to advanced database design and query optimization. SQL is the standard language for interacting with relational database management systems (RDBMS) and is a critical skill for any Full-Stack Engineer.

## Learning Objectives
By the end of this module, you will be able to:
- Understand relational database theory and why it matters in modern applications
- Write complex queries using filtering, aggregation, and joins
- Utilize advanced SQL features like Subqueries and Common Table Expressions (CTEs)
- Design normalized database schemas with proper constraints and relationships
- Apply indexing strategies to optimize query performance
- Understand ACID properties and how transactions work
- Analyze and improve query execution plans

## Module Structure

### Lessons
1. **[01. Relational Database Concepts](./lessons/01-relational-database-concepts.md)** - What relational databases are, tables/rows/columns, primary keys, foreign keys, relationships, why relational model exists
2. **[02. SQL Fundamentals](./lessons/02-sql-fundamentals.md)** - SELECT, INSERT, UPDATE, DELETE, WHERE, ORDER BY, LIMIT, OFFSET, aliases
3. **[03. Filtering and Operators](./lessons/03-filtering-and-operators.md)** - WHERE conditions, AND/OR/NOT, IN, BETWEEN, LIKE, IS NULL, comparison operators
4. **[04. Joins](./lessons/04-joins.md)** - INNER JOIN, LEFT JOIN, RIGHT JOIN, FULL OUTER JOIN, CROSS JOIN, self join. Venn diagrams. Many examples.
5. **[05. Aggregation](./lessons/05-aggregation.md)** - COUNT, SUM, AVG, MIN, MAX, GROUP BY, HAVING, aggregate with joins
6. **[06. Subqueries](./lessons/06-subqueries.md)** - Scalar subqueries, row subqueries, table subqueries, correlated subqueries, EXISTS, IN with subqueries
7. **[07. CTEs](./lessons/07-ctes.md)** - Common Table Expressions, WITH clause, recursive CTEs, readability, vs subqueries
8. **[08. Constraints](./lessons/08-constraints.md)** - NOT NULL, UNIQUE, PRIMARY KEY, FOREIGN KEY, CHECK, DEFAULT, composite keys, referential integrity
9. **[09. Normalization](./lessons/09-normalization.md)** - 1NF, 2NF, 3NF, BCNF, why normalize, when to denormalize, practical examples
10. **[10. Indexes](./lessons/10-indexes.md)** - B-tree indexes, hash indexes, composite indexes, covering indexes, index selectivity, when to index
11. **[11. Transactions](./lessons/11-transactions.md)** - ACID properties, BEGIN/COMMIT/ROLLBACK, isolation levels (READ UNCOMMITTED, READ COMMITTED, REPEATABLE READ, SERIALIZABLE)
12. **[12. Views](./lessons/12-views.md)** - Creating views, updatable views, materialized views, use cases
13. **[13. Database Design](./lessons/13-database-design.md)** - ER diagrams, entity identification, relationship mapping, schema design process, practical examples
14. **[14. Query Optimization](./lessons/14-query-optimization.md)** - EXPLAIN, execution plans, index usage, query rewriting, avoiding N+1
