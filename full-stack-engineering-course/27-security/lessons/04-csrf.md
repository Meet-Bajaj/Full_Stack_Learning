# Lesson 4: Cross-Site Request Forgery (CSRF)

## Learning Objectives
- Understand how CSRF attacks work.
- Implement CSRF tokens.
- Use `SameSite` cookies.

## How CSRF Works
An attacker tricks a victim into submitting a malicious request on a site where they are already authenticated. (e.g., an invisible form submits a money transfer request to your bank).

## Prevention
1. **CSRF Tokens**: A unique, secret, unpredictable value generated by the server and included in every state-changing request (like POST).
2. **SameSite Cookies**: Setting `SameSite=Lax` or `Strict` on cookies prevents the browser from sending them with cross-site requests. Modern browsers default to `Lax`.
