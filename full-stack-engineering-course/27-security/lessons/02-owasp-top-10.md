# Lesson 2: OWASP Top 10

## Learning Objectives
- Familiarize yourself with the OWASP Top 10 (2021).
- Understand the most critical web application security risks.

## Overview of Risks
1. **Broken Access Control**: Users acting outside their permissions.
2. **Cryptographic Failures**: Exposing sensitive data due to weak encryption.
3. **Injection**: SQL, NoSQL, and OS command injections.
4. **Insecure Design**: Flaws in architecture.
5. **Security Misconfiguration**: Default configs, open cloud storage.
6. **Vulnerable and Outdated Components**: Using old npm/pip packages with CVEs.
7. **Identification and Authentication Failures**: Brute force, session hijacking.
8. **Software and Data Integrity Failures**: Unsigned code, CI/CD pipeline vulnerabilities.
9. **Security Logging and Monitoring Failures**: Not detecting breaches in time.
10. **SSRF (Server-Side Request Forgery)**: Forcing the server to make unauthorized requests.
