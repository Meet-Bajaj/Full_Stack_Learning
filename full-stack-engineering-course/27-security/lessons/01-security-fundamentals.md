# Lesson 1: Security Fundamentals

## Learning Objectives
- Define the CIA Triad (Confidentiality, Integrity, Availability).
- Understand Defense in Depth and Least Privilege.
- Learn Threat Modeling basics.

## The CIA Triad
- **Confidentiality**: Only authorized users can access data.
- **Integrity**: Data cannot be modified improperly.
- **Availability**: Systems are available to authorized users when needed.

## Defense in Depth (Mental Model)
Think of a medieval castle. You don't just have one door. You have a moat, a wall, guards, and a secure keep. In software: WAF -> Network Firewall -> App Auth -> Input Validation -> Database Encryption.
