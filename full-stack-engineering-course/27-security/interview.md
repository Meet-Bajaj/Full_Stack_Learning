# Module 27 Interview Questions

## Junior Level
- What is Cross-Site Scripting (XSS) and how do you prevent it?
- Why do we hash passwords instead of encrypting them?

## Mid Level
- Explain how a CSRF attack works and how a CSRF token mitigates it.
- What is CORS and why is it important for API security?
- Describe the difference between Authentication and Authorization.

## Senior Level
- How would you design a secure session management system using JWTs?
- Explain Broken Object Level Authorization (BOLA) and how to architect defenses against it.
- How do you secure a Docker container for a production deployment?
