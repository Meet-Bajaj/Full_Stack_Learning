# Module 27: Security MCQs

1. **What is the primary defense against SQL Injection?**
   - A) Base64 Encoding
   - B) WAF (Web Application Firewall)
   - C) Parameterized Queries
   - D) HTTPS
   - **Answer**: C
   - **Explanation**: Parameterized queries ensure user input is treated strictly as data, not executable code.

2. **Which vulnerability involves an attacker forcing a user's browser to execute unwanted actions on a trusted site?**
   - A) XSS
   - B) CSRF
   - C) SSRF
   - D) RCE
   - **Answer**: B
   - **Explanation**: Cross-Site Request Forgery (CSRF) exploits the trust a site has in a user's browser (specifically cookies).
