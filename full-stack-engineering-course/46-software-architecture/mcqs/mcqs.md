# Software Architecture MCQs

## Beginner Level

**Q1. What is the primary difference between software architecture and software design?**
- A) Architecture is about code structure; design is about database schemas.
- B) Architecture deals with high-level decisions that are hard to change; design deals with low-level component organization.
- C) Architecture is done by managers; design is done by developers.
- D) There is no difference; they are synonyms.
**Correct Answer:** B
**Explanation:** Architecture focuses on systemic, hard-to-change decisions, while design focuses on internal, easier-to-change implementations.
**Topic:** Architecture Fundamentals
**Subtopic:** Architecture vs Design

**Q2. Which of the following is considered a Non-Functional Requirement (Quality Attribute)?**
- A) The system must allow users to reset their passwords.
- B) The system must generate a monthly PDF report.
- C) The system must handle 10,000 concurrent users with <200ms latency.
- D) The system must integrate with Stripe for payments.
**Correct Answer:** C
**Explanation:** Latency and concurrency are quality attributes (performance/scalability), not specific functional features.
**Topic:** Quality Attributes
