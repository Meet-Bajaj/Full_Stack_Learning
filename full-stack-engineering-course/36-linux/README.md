# Module 36: Linux

## Overview
Linux is the dominant operating system for web servers. Mastery of Linux, the command line, and server administration is crucial for full-stack developers.

## Learning Objectives
- Navigate the Linux filesystem efficiently
- Manage files, permissions, and users
- Handle processes and networking
- Use SSH for remote administration
- Write shell scripts for automation
- Secure and harden Linux servers
