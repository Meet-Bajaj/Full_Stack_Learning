# Exercises

1. Initialize a new Prisma project with PostgreSQL.
2. Create a schema with `User`, `Post`, and `Comment` models including 1-N and M-N relations.
3. Write a script to seed the database with 10 users and 50 posts using `createMany`.
4. Write a query to find all users who have written at least one post containing the word "Prisma".
5. Implement an interactive transaction to transfer authorship of a post from one user to another.
