# Prisma MCQs

**Q1: Which command applies pending migrations to a production database?**
A) `prisma migrate dev`
B) `prisma migrate deploy`
C) `prisma db push`
D) `prisma migrate resolve`
**Answer:** B

**Q2: How do you prevent SQL injection when using raw queries in Prisma?**
A) By manually escaping strings
B) By using `$queryRawUnsafe`
C) By using tagged template literals with `$queryRaw`
D) Prisma automatically escapes all raw queries
**Answer:** C
