# Module 21: Prisma

## Overview
Prisma is a next-generation ORM for Node.js and TypeScript. It offers a type-safe database client, intuitive data modeling, and an automated migration system.

## Learning Objectives
- Understand ORM concepts and Prisma architecture.
- Master the Prisma Schema and relations.
- Perform advanced CRUD operations and transactions.
- Optimize performance and integrate with NestJS.

## Structure
- `lessons/`: Comprehensive guides and tutorials.
- `exercises/`: Practical tasks.
- `mcqs/`: Multiple-choice questions.
- `projects/`: Real-world implementation tasks.
