# Module 28: Performance MCQs

1. **Which Core Web Vital measures visual stability?**
   - A) LCP
   - B) FID
   - C) CLS
   - D) TTFB
   - **Answer**: C
   - **Explanation**: Cumulative Layout Shift (CLS) measures unexpected layout shifts during page load.

2. **What is the best way to solve the N+1 query problem?**
   - A) Add more indexes to the database
   - B) Upgrade the database server
   - C) Use JOINs or a batching library like DataLoader
   - D) Compress the database connection
   - **Answer**: C
   - **Explanation**: Batching or joining reduces the number of round trips to the database from N+1 down to 1 or 2 queries.
