# Lesson 1: Performance Fundamentals

## Learning Objectives
- Differentiate between measurement and optimization.
- Understand Core Web Vitals (TTFB, FCP, LCP, CLS, INP).

## Core Web Vitals
- **LCP (Largest Contentful Paint)**: Loading performance. Should be < 2.5s.
- **FID / INP (Interaction to Next Paint)**: Interactivity.
- **CLS (Cumulative Layout Shift)**: Visual stability. Should be < 0.1.

## The Performance Mindset
*Mental Model*: Think of performance as a budget. You only have so many milliseconds to deliver the experience. Every third-party script, large image, or blocking API call spends that budget.
