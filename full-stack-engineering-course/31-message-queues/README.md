# Module 31: Message Queues

## Overview
This module introduces message queues and event-driven architecture for asynchronous processing and decoupled microservices.

## Learning Objectives
- Differentiate between point-to-point and pub/sub
- Implement job queues using BullMQ
- Understand the architecture of RabbitMQ and Kafka
- Apply queuing patterns like fan-out, dead letter queues, and priority queues

- `lessons/`: MQ fundamentals and specific technologies
- `exercises/`: Hands-on queuing exercises
- `mcqs/`: Assessment questions
- `interview.md`: Interview preparation
