# Message Queues MCQs

1. **Question:** In Kafka, how is horizontal scalability achieved?
   - A) By adding more Exchanges.
   - B) By partitioning topics across multiple brokers.
   - C) By increasing the Dead Letter Queue limit.
   - D) By using Redis in-memory storage.
   - **Correct Answer:** B
   - **Explanation:** Kafka partitions a single topic across multiple brokers, allowing multiple consumers in a group to read in parallel.
   - **Difficulty:** Intermediate
