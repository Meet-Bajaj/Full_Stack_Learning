# Module 23: MinIO

## Overview
MinIO is a high-performance, S3-compatible object storage server. It is built for large scale AI/ML, data lake, and database workloads.

## Learning Objectives
- Understand Object Storage vs File/Block storage.
- Deploy and configure MinIO using Docker.
- Manage buckets, policies, and presigned URLs.
- Integrate MinIO with Node.js and NestJS applications.
