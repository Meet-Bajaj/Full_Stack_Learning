# JavaScript Exercises

## Basics (Variables, Types, Operators)
1. Write a script that checks if a number is even or odd using the modulo operator.
2. Given a string, write a function to reverse it without using the built-in `.reverse()` method.
3. Use the ternary operator to assign "Adult" if age is >= 18, else "Minor".

## Functions & Scope
4. Write a function `calculateArea(radius)` that returns the area of a circle. Provide a default value of 1 for the radius.
5. Create an IIFE (Immediately Invoked Function Expression) that logs "System initializing...".
6. Write a closure function `createMultiplier(x)` that returns a function which multiplies its input by `x`.

## Arrays & Objects
7. Write a function `removeDuplicates(arr)` that takes an array and returns a new array with duplicates removed (Hint: Use `Set`).
8. Given an array of numbers, use `.reduce()` to find the maximum value.
9. Write a function that takes an object `{a: 1, b: 2, c: 3}` and returns an array of its keys `['a', 'b', 'c']`.

## Destructuring & Spread
10. Destructure the nested object `{ user: { name: 'Alice', details: { age: 30 } } }` to extract the `age` variable in one line.
11. Merge two arrays `arr1 = [1,2]` and `arr2 = [3,4]` using the spread operator.
12. Write a function `sumAll(...args)` that accepts any number of arguments and returns their sum.

## Async JavaScript
13. Create a Promise that resolves with "Success!" after 2 seconds.
14. Rewrite the Promise from Exercise 13 using `async/await`.
15. Write a script using `fetch` to get data from `https://jsonplaceholder.typicode.com/todos/1` and log the title.
