# MongoDB Module Assessment

## Part 1: Schema Architecture
1. You are building a Twitter clone. Explain how you would model the relationship between a `User` and their `Tweets`. Would you embed the tweets inside the user document or reference them? Defend your answer referencing MongoDB limits.
2. What is the difference between a flexible schema and a schemaless database? How does Mongoose bridge this gap?

## Part 2: Query Writing
Given a `products` collection:
1. Write a query to find all products where `price` is greater than $50 and `inStock` is true.
2. Write a query to update a product with `_id: 123` by adding "bestseller" to its `tags` array. (Do not overwrite the existing tags).

## Part 3: Aggregation
Given an `orders` collection where each document has a `customerId`, `status` ("pending", "shipped", "delivered"), and `totalAmount`.
1. Write an aggregation pipeline to find the total revenue (`totalAmount`) generated by "delivered" orders, grouped by `customerId`.

## Part 4: Performance & Production
1. A developer runs `db.users.find({ email: "test@test.com" })` and it takes 2 seconds. The collection has 5 million documents. Explain exactly what is happening under the hood (COLLSCAN) and write the exact code to fix it.
2. Explain what a Replica Set is and why a standalone MongoDB instance should never be used in production.
